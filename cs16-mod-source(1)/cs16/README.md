# CS 1.6 для Minecraft 1.21.11 (Fabric)
Сборка: `gradle build` (Java 21) -> build/libs/cs16-1.0.0.jar (+ Fabric API в mods)
B — магазин (оружие, броня, аптечка, гранаты, набор сапёра)
F6 — включить/выключить режим CS (по умолчанию выключен = обычное прохождение). При включении сразу выдаётся нож.
ЛКМ — выстрел (можно зажать), ПКМ — зум (только снайперки: Scout, AWP, SG 550, G3SG1), R — перезарядка (патроны: обойма/запас, как в CS). Команды: /shop /buy <id> /money /csmode /csreload. Старт $800, +$300 за убийство.

## Сборка jar без установки Java
Залей папку в новый репозиторий на github.com -> вкладка Actions -> build -> внизу Artifacts -> cs16-mod (там .jar).

Пули ломают мягкие блоки (твёрдость блока <= урон/4: AK-47 — земля, песок, стекло, камень; AWP — ещё и руды). Бедрок и обсидиан не ломаются.

Нож: ПКМ по блоку — несколько ударов ломают даже обсидиан (5 ударов; бедрок не ломается). В режиме F6 не работает.

Нож: удар в спину мобу/игроку наносит 40 урона (в режиме CS). Меняется константа BACKSTAB_DAMAGE в Knife.java.

В режиме CS (F6): авто-бхоп (держи пробел — скорость копится от прыжка к прыжку, потолок ~12 блоков/с) и парашют (E в падении — медленное планирование, без урона от падения; в режиме CS инвентарь не открывается, в обычном (F6) работает как всегда).
